# Редактор: окна и управление

Интерфейс движка поверх сцены устроен как редактор UE:
- главное меню сверху;
- слева Outliner (что есть на уровне), справа Details (свойства выбранного), снизу Output (консоль и лог);
- в центре — сцена с оверлеем FPS и времени кадра.

Панели прилипают к краям экрана и складываются вкладками (ImGui ветки docking). Перетащить панель за заголовок — к
другому краю или вкладкой к соседней; «Window → Reset layout» — раскладка по умолчанию. Раскладка запоминается в
`imgui_editor.ini` в корне проекта (не в git). Код — `src/Engine/Graphics/GUI/`.

## Управление

| Клавиша | Что |
|---|---|
| правая кнопка мыши + мышь | смотреть камерой — над сценой, не над панелями; курсор прячется и возвращается на место |
| W A S D, пробел / C | двигать камеру |
| I | режим полёта: камера смотрит мышью всегда, без правой кнопки |
| G | вид игры: редактор скрыт, камера смотрит мышью |
| Q | каркас |
| 1 | рельеф вкл / выкл |
| 3 / 4 | расстановка: расчёт / отрисовка |
| P | снимок с окнами редактора (`screenshotN.jpg`) |
| Ctrl+S | сохранить окружение уровня |
| `` ` `` | консоль |
| Ctrl + клик по ползунку | ввести число |
| Esc | выход |

Пока набирается текст (поиск, консоль), горячие клавиши и WASD не срабатывают. Список — «Help → Hotkeys».
С `-nomouse` камера мышь не читает совсем, как раньше.

## Меню

- **File** — действия: «Save level environment» (Ctrl+S), «Exit». Действия выполняет и консольная команда
  `action "<имя>"` (удалённое управление, [remote.md](remote.md)).
- **View** — переключатели с отметкой состояния: каркас, рельеф, расстановка, режим полёта, вид игры; оверлей кадра.
  Это те же горячие клавиши — меню нажимает их (`KeyEventNotifier::press`).
- **Window** — панели вкл / выкл, «Reset layout».
- **Help** — горячие клавиши.

Справа в меню — «Level environment changed — Ctrl+S to save», пока окружение изменено после загрузки или сохранения.

## Панели

- **Outliner** — окна свойств по разделам:
  - **Environment** — то, что пишет «Save level environment»: свет и время суток, небо или панорама, облака, туман,
    постобработка, ветер;
  - **Scene** — объекты сцены: террейн, модели, вода, наборы расстановки, частицы;
  - **Rendering** — рендерер и тени.

  Флажок слева — видимость объекта сцены (`SceneObject::setVisible`). Звёздочка — есть изменения после загрузки или
  сохранения. Поиск по имени.
- **Details** — свойства выбранного таблицей «имя | значение | reset»:
  - подконтейнеры (подокно солнца, слой расстановки) — сворачиваемые заголовки;
  - изменённое после загрузки или сохранения подсвечено; «reset» возвращает свойство, «Reset all» — всё окно;
  - поиск по свойствам (под поиском заголовки раскрыты);
  - наведение на имя — полное имя, единицы и подсказка;
  - формат числа — по величине (0,0003 не превращается в 0,000), величины в несколько порядков — логарифмический
    ползунок.
- **Output** — вкладки:
  - **Console** — те же команды, что у удалённого управления: строка выполняется в начале следующего кадра, ответ — в
    окне. ↑ / ↓ — история, Tab — дополнение имени команды и пути свойства для `get` / `set` / `list` (путь с
    пробелами — в кавычках);
  - **Log** — последние 2000 строк `log.txt` с поиском, ошибки красным, предупреждения жёлтым, флажок «только ошибки
    и предупреждения».
- **Stats** — таблица времени CPU и GPU проходов и объектов (сортировка по колонке) и прочие счётчики кадра (память,
  кольцо констант, барьеры). Оверлей поверх сцены — FPS, кадр CPU и GPU и графики за 300 кадров.
- **Camera** — положение, направление, строка `x,y,z,pitch,yaw` для команды `camera` и параметра `-Camera` с кнопкой
  копирования, скорость камеры.
- **Texture Library** (Window) — текстуры хранилища миниатюрами с поиском, наведение — крупно с id и размером.

## Как дать объекту свойства

Объект сцены отдаёт `properties()` — `PropertyContainer` (`src/Common/Properties`); `DMGraphics::Initialize` регистрирует
его в Outliner (`GUI::addPropertyWatching( контейнер, раздел, объект )`). Раздел Environment у объекта —
`SceneObject::environment()`. Контролы панель строит сама по типу значения и `GUIControlType`. Необязательно:

```cpp
properties.insert( "Density", density )->setLow( 0.0f );            // как раньше
property->setUnit( "1/m" )->setLogarithmic()->setFormat( "%.5f" )
        ->setTooltip( "Extinction coefficient; visibility ~3 / density" );
```

Значения при регистрации — «сохранённые»: от них считается «изменено». После сохранения уровня `GUI::markSaved`
обновляет их у раздела Environment. Удалённое управление (`list` / `get` / `set`) видит те же свойства по путям
`окно/подокно/свойство`.

## Устройство

| Файл | Что |
|---|---|
| `GUI.h/.cpp` | оболочка: кадр, меню, раскладка (dockspace и `DockBuilder`), стиль и масштаб по DPI, уведомления, действия и переключатели |
| `OutlinerPanel`, `DetailsPanel` | списки окон свойств и свойства выбранного |
| `PropertyWidgets` | контролы свойств таблицей, поиск, сброс |
| `StatsPanel` | оверлей и таблица времени (из `FrameStats`: строки «имя = формат») |
| `ConsolePanel` | консоль (дополнение, история) и лог (`Logger::recent`) |
| `CameraPanel`, `TextureLibraryPanel` | камера, текстуры |
| `EditorTypes.h` | раздел, запись Outliner, действие, переключатель |

Цвета темы заданы в sRGB и переводятся в линейные: задний буфер пишется через sRGB-вид. Масштаб — по DPI окна
(`GetDpiForWindow`), шрифт — Segoe UI из Windows (с кириллицей), без него — встроенный. ImGui — ветка docking
1.92.9b: архив `DownloadResources/imgui-1.92.9b-docking.zip`, если он есть, иначе с GitHub (`CMakeLists.txt`).
