# Документация DMEngine

Описание возможностей движка: как устроена подсистема, какие данные она берёт из `base.db3`, как добавить
свой контент и что проверить, если результат не тот. Сборка, запуск и соглашения по коду — в `CLAUDE.md`,
план доработок — в `TODO.md`.

## Разделы

| Раздел | О чём |
|---|---|
| [Освещение](lighting.md) | Общая функция освещения материалов, источники света уровня (`LevelLights`, правка в GUI): направленный, точечный, прожектор, затухание, конус |
| [Тени солнца](shadows.md) | Каскадные карты теней (как CSM в UE): каскады, стабилизация, PCF, смещения, настройки у солнца (`LevelLights`) |
| [Небо и освещение окружением](sky.md) | Процедурная атмосфера (Hillaire 2020, как Sky Atmosphere в UE5), IBL: гармоники, отражения, таблица BRDF |
| [Кадр: HDR, экспозиция и тонмаппинг](postprocess.md) | HDR-буфер сцены, постобработка, AgX и ACES, настройки `PostProcessSettings`, яркости света |
| [Модели: импорт из Blender](models.md) | Экспорт glTF из Blender, `Tools/import_gltf.py`: LOD, материалы, расстановка на уровне, повторный импорт |
| [Материалы и PBR](materials.md) | Материал `PBR` (metallic/roughness как в glTF), экземпляры материалов, цветовые пространства, освещение |
| [Расстановка (скаттер)](scatter.md) | Трава, цветы, камешки и веточки вокруг камеры: наборы, слои, кольца, маски плотности |

## Соглашения

- Единицы: расстояния — метры мира, углы в базе — градусы.
- Мир: ось Y вверх, система координат левая (Direct3D). Террейн лежит в квадрате `[0, worldSize]` по X и Z.
- Ресурсы (текстуры, модели, материалы) ссылаются друг на друга по именам или id из таблиц `base.db3`;
  отсутствующий файл заменяется заглушкой (шахматка, примитив), и об этом пишется в `log.txt`.
- Раздел обновляется вместе с кодом подсистемы: изменили поведение или данные — поправьте и документ.
