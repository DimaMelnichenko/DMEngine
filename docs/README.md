# Документация DMEngine

Описание возможностей движка: как устроена подсистема, какие данные она берёт из `base.db3`, как добавить
свой контент и что проверить, если результат не тот. Сборка, запуск и соглашения по коду — в `CLAUDE.md`,
план доработок — в `TODO.md`.

## Разделы

| Раздел | О чём |
|---|---|
| [Освещение](lighting.md) | Общая функция освещения материалов, источники света уровня (`LevelLights`, правка в GUI): направленный, точечный, прожектор, затухание, конус; солнце через атмосферу и время суток (`SunPosition`) |
| [Тени солнца](shadows.md) | Каскадные карты теней (как CSM в UE): каскады, стабилизация, PCF, смещения, настройки у солнца (`LevelLights`) |
| [Небо и освещение окружением](sky.md) | Процедурная атмосфера (Hillaire 2020, как Sky Atmosphere в UE5), воздушная перспектива, HDRI-панорама вместо атмосферы (`HDRIBackdrop`), IBL: гармоники, отражения, таблица BRDF |
| [Проходы кадра и depth prepass](passes.md) | Порядок проходов, раскладка мешей и своих вызовов, depth prepass: глубина до цвета, проверка `EQUAL`, Masked без `clip`, переключатель `DepthPrepass` |
| [Кадр: HDR, экспозиция, bloom и тонмаппинг](postprocess.md) | HDR-буфер сцены, физические единицы, EV100 и автоэкспозиция, pre-exposure, bloom, AgX и ACES, настройки `PostProcessSettings`, яркости света |
| [Модели: импорт из Blender](models.md) | Экспорт glTF из Blender, `Tools/import_gltf.py`: LOD, материалы, расстановка на уровне, повторный импорт |
| [Материалы и PBR](materials.md) | Материал `PBR` (metallic/roughness как в glTF), экземпляры материалов, цветовые пространства, освещение |
| [Террейн](terrain.md) | CDLOD, до 8 слоёв материала из фото-текстур (`Tools/pack_terrain_layer.py`), splat-карта из двух RGBA, sRGB-альбедо, triplanar, смешивание по высоте, второй масштаб вдали |
| [Расстановка (скаттер)](scatter.md) | Трава, цветы, камешки и веточки вокруг камеры: наборы, слои, кольца, маски плотности |
| [Удалённое управление](remote.md) | Команды запущенному движку (`Tools/engine.py`, канал `\\.\pipe\DMEngine`): камера, снимок заднего буфера, время GPU, свойства GUI, клавиши, выход — серия проверок за один запуск |

## Соглашения

- Единицы: расстояния — метры мира, углы в базе — градусы.
- Мир: ось Y вверх, система координат левая (Direct3D). Террейн лежит в квадрате `[0, worldSize]` по X и Z.
- Ресурсы (текстуры, модели, материалы) ссылаются друг на друга по именам или id из таблиц `base.db3`;
  отсутствующий файл заменяется заглушкой (шахматка, примитив), и об этом пишется в `log.txt`.
- Раздел обновляется вместе с кодом подсистемы: изменили поведение или данные — поправьте и документ.
